# Uploading Sisonke to GitHub

1. Extract this ZIP.
2. Upload the CONTENTS of the extracted folder to the root of your GitHub repository.
3. Do not upload generated folders such as build/ or .dart_tool/.
4. Keep pubspec.yaml, lib/, assets/, and supabase/ at the repository root.

This corrected package contains the full Sisonke Live MVP v4 source currently available in the project archive.
